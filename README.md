# 402 鼠王争霸赛

一个记录每一餐、一起评选“鼠王”的轻量网页应用。

- 在线体验：https://wastonyuxxxxx.github.io/402-remy-standings/
- 当前部署：GitHub Pages
- 默认语言：简体中文
- 适合场景：朋友聚餐、家庭做饭、餐次与菜品评分

## 当前功能

- 主厨榜：按累计分、平均分、最佳三餐查看排名
- 菜品榜：查看菜品表现
- 发布与编辑餐次
- 评委打分流程
- 厨师与历史餐次管理
- 移动端优先的响应式界面

## 发布结构

这是一个可直接由 GitHub Pages 托管的静态发布包。入口文件为 `index.html`，运行时资源位于 `assets/`。

仓库只保留当前入口实际引用的构建资源，避免历史构建文件重复占用空间；页面元信息、键盘焦点样式和减少动效支持也已在入口层补齐。
