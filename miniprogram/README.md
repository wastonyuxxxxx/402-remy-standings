# 微信小程序测试入口

这一目录是现有 V1 网站的最小 `web-view` 入口，不复制或重写网站界面。网页仍由 GitHub Pages 发布；小程序打开 `https://wastonyuxxxxx.github.io/402-remy-standings/`，因此两端看到同一套页面和线上数据。

## 用测试号体验

1. 在微信开发者工具中导入本目录 `miniprogram/`。已配置测试号 AppID `wx9493cc16e348b1ff`；AppID 是公开标识，随工程提交，方便跨设备打开。不要把 AppSecret 填进小程序代码或提交到 GitHub。开发者工具生成的 `project.private.config.json` 只留在本机。
2. 在开发者工具的项目设置中，只为**本地测试**启用“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”，然后编译。测试号能否在真机打开仍需实际预览确认。
3. 在微信中重点检查：页面加载、照片选择与上传、菜品识别进度、结果弹窗滚动与修改、发布这餐、评委打分。任何失败都记录具体步骤和截图。

开发工具跳过域名校验不等于已满足正式发布条件。正式上线前须按届时的微信平台要求确认账号主体、业务域名验证和站点域名可用性。当前 GitHub Pages 域名是否符合要求尚未验证，不应据此承诺可直接上架。

`web-view` 内的网站身份仍由原网页管理；小程序测试号 AppID 不会自动把网页的匿名用户变成微信账号。以后如果要求网页与小程序共用同一个可恢复身份，需要单独设计登录关联。
